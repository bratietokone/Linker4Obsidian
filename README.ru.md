# Linker4

**Язык документации:** [English](README.md) | [Русский](README.ru.md) | [Español](README.es.md) | [简体中文](README.zh-CN.md)

Плагин для настольной версии [Obsidian](https://obsidian.md/), который автоматически встраивает вложения, но оставляет ссылки на Markdown-заметки обычными Wiki-ссылками. Также преобразует отдельные YouTube URL во встроенный видеоплеер.

**Версия:** 0.5.0 · **Статус:** релиз GitHub с ручной установкой · **Требования:** Obsidian 1.8.7 или новее (Windows, macOS, Linux). Плагин пока не опубликован в официальном каталоге Community Plugins.

## Возможности

- Markdown-заметки остаются ссылками `[[note.md]]`; изображения, PDF, аудио и видео автоматически получают формат встраивания `![[file.ext]]` по настраиваемым правилам.
- Обработка новых Wiki-ссылок при наборе, вставке и выборе через встроенное автодополнение `[[`.
- Встраивание YouTube (`youtube.com`, `youtu.be`, Shorts, `/live/`) в виде `![](URL)` при вставке в подходящее место или при преобразовании существующих заметок.
- Предварительный просмотр перед изменением ссылок в текущей заметке или во всём хранилище.
- Выбор языка интерфейса: **Автоматически (язык Obsidian)**, **English**, **Русский**, **Español** и **简体中文**. Настройки, диалоги и уведомления переводятся сразу; имена команд — после перезагрузки плагина.
- Не требуется аккаунт, сервер или отправка содержимого заметок во внешние сервисы.

- **Внешние файлы и папки:** создание Markdown-ссылок `file:///` и Wiki-ссылок `[[external:...]]` на объекты за пределами хранилища без копирования файлов.

> **Переход с Linker4Obsidian 0.4.0 и более ранних версий:** ID изменился с `linker4obsidian` на `linker-four`. Отключите старый плагин, установите Linker4 0.5.0 или новее в `.obsidian/plugins/linker-four/` и при необходимости скопируйте `data.json` для сохранения настроек. Проверьте новую установку перед удалением старой папки. Старые релизы используют другой ID.

## Установка в Windows, macOS и Linux

> Перед первой установкой и массовым преобразованием ссылок сделайте резервную копию хранилища либо сначала проверьте плагин в тестовом хранилище.

Порядок установки **одинаков на всех настольных операционных системах**. Сейчас требуется ручная установка, поскольку плагин ещё не добавлен в официальный каталог Obsidian.

1. Откройте [GitHub Releases](https://github.com/bratietokone/Linker4Obsidian/releases) (пока репозиторий приватный, нужен доступ). В разделе **Assets** нужного релиза скачайте `main.js` и `manifest.json` либо архив `linker4-vX.Y.Z.zip` и распакуйте его.
2. Найдите нужное **хранилище Obsidian (vault)**, а не каталог установки приложения. Внутри хранилища откройте или создайте скрытый каталог `.obsidian/plugins/linker-four/`.
3. Поместите оба файла в папку, сохранив имена. В ZIP уже есть каталог `linker-four/`, который должен находиться внутри `.obsidian/plugins/`:

   ```text
   YourVault/
   └── .obsidian/
       └── plugins/
           └── linker-four/
               ├── manifest.json
               └── main.js
   ```

4. Перезапустите Obsidian или перезагрузите сторонние плагины. Откройте **Настройки → Сторонние плагины (Community plugins)**, при необходимости разрешите их использование и включите **Linker4**.
5. Откройте настройки **Linker4**, выберите язык и правила встраивания.

### Где находится папка плагинов?

| Система | Пример пути | Как показать скрытые каталоги |
| --- | --- | --- |
| Windows | `C:\Users\<user>\Documents\MyVault\.obsidian\plugins\linker-four\` | Проводник → **Вид → Показать → Скрытые элементы** (названия зависят от версии Windows). |
| macOS | `/Users/<user>/Documents/MyVault/.obsidian/plugins/linker-four/` | Finder: **Cmd+Shift+.** |
| Linux | `/home/<user>/Documents/MyVault/.obsidian/plugins/linker-four/` | В большинстве файловых менеджеров: **Ctrl+H**. |

Это **примеры**, а не обязательные места хранения. Vault может находиться где угодно: на другом диске, в синхронизируемой папке и т. д. Папка `.obsidian` находится именно **внутри хранилища**. Не создавайте второй вложенный каталог `linker-four/linker-four/`.

## Выбор языка интерфейса

Откройте **Настройки → Linker4 → Язык интерфейса**:

| Вариант | Как работает |
| --- | --- |
| Автоматически (по умолчанию) | Язык интерфейса Obsidian: русский при выборе русского, английский для неподдерживаемых языков. |
| English | Английский независимо от настроек Obsidian. |
| Русский | Русский независимо от настроек Obsidian. |
| Español | Испанский независимо от настроек Obsidian. |
| 简体中文 | Упрощённый китайский независимо от настроек Obsidian. |

Настройки переключаются сразу, а уведомления и диалоги преобразования отображаются на выбранном языке. **Перезагрузите плагин**, чтобы названия команд в палитре тоже обновились. Все переводы интерфейса находятся в отдельных проверяемых TypeScript-модулях `src/locales/`.

## Правила по умолчанию

| Содержимое | Результат |
| --- | --- |
| Заметки Markdown (`.md`, `.markdown`) | `[[Notes/My note.md]]` |
| Изображения (`.png`, `.jpg`, `.webp`, `.svg` и др.) | `![[photo.webp]]` |
| Документы PDF | `![[document.pdf]]` |
| Локальное видео (`.mp4`, `.webm` и др.) | `![[video.mp4]]` |
| Локальное аудио (`.mp3`, `.flac` и др.) | `![[audio.mp3]]` |
| Неизвестные расширения | `[[archive.zip]]` |
| Отдельная ссылка на видео YouTube | `![](https://www.youtube.com/watch?v=VIDEO_ID)` |
| Другие веб-сайты | Обычная ссылка |

Категории и дополнительные расширения можно настроить. Правило **«Всегда оставлять ссылкой»** приоритетнее **«Всегда встраивать»**. Показ встроенного файла зависит от поддержки его формата в Obsidian.

## Внешние файлы и папки

В **Настройки → Linker4 → Внешние файлы и папки** добавлена отдельная страница. Можно включить обработку внешних ссылок и выбрать формат создаваемых ссылок — Markdown или Wiki. При этом открытие поддерживает оба формата независимо от настройки.

```markdown
[Проекты](<file:///home/user/Projects/>)
[Отчёт](<file:///home/user/Documents/report.pdf>)

[[external:/home/user/Projects/|Проекты]]
[[external:/home/user/Documents/report.pdf|Отчёт]]
```

Для вставки используйте команды **Вставить ссылку на внешний файл** и **Вставить ссылку на внешнюю папку**. Там можно выбрать объект через системный диалог (если доступен) либо вручную указать абсолютный путь. Название ссылки можно отредактировать.

Нажатие в режиме чтения или Live Preview открывает файл приложением по умолчанию, а папку — файловым менеджером. В настройках можно выбрать вместо открытия показ объекта в файловом менеджере. Исполняемые файлы только показываются, но не запускаются. Отсутствующие файлы и некорректные пути вызывают уведомление. Сетевые файловые URI и другие схемы не поддерживаются.

**Важно:** внешние файлы не встраиваются и не копируются в хранилище. Прежняя обработка вложений не изменяется.

## Использование

- **Новые ссылки:** введите Wiki-ссылку или выберите файл через автодополнение `[[` — плагин применит правило типа файла.
- **Перетаскивание и вставка файлов:** если Obsidian создаёт Wiki-ссылку, плагин нормализует её. За копирование файлов в хранилище отвечает сам Obsidian.
- **YouTube:** вставьте URL ролика в подходящую строку. URL внутри обычного предложения не преобразуется автоматически, чтобы не изменять ваш текст без необходимости.
- **Существующие заметки:** откройте палитру команд (`Ctrl+P` / `Cmd+P`) и выберите **Linker4: Предпросмотр и преобразование ссылок в текущей заметке** или **Linker4: Предпросмотр и преобразование ссылок во всём хранилище**. Просмотрите изменения и подтвердите их.

Плагин сохраняет уже созданные `![[...]]`, не переписывает огороженные блоки кода, YAML frontmatter, встроенный код и строки HTML-комментариев. Массовое преобразование требует подтверждения. **Перед ним сделайте резервную копию.**

## Ограничения

- Внешние пути должны быть абсолютными, зависят от устройства и могут быть недоступны из песочницы (например, Flatpak).
- Версия предназначена **только для настольного Obsidian**, не для мобильного приложения.
- Встраиваются поддерживаемые URL отдельных YouTube-видео; ссылки только на плейлист и другие сайты остаются обычными ссылками. Плагин не обходит запреты сайтов на iframe.
- Обычные Markdown-ссылки на локальные файлы `[file](image.png)` не преобразуются в Wiki-встраивания.
- Автоматически обрабатываются новые ссылки; для старых используйте команды преобразования.
- На создание ссылок могут влиять другие плагины и версии редактора Obsidian. Ошибки можно описывать в GitHub Issues.

## Разработка

Требуются Node.js и npm. Исходный код находится в `src/`, переводы — в `src/locales/`, готовые `main.js` и `manifest.json` — в корне репозитория.

```bash
npm install
npm run typecheck
npm run build
npm test
```

GitHub Actions запускает эти проверки при обновлениях и pull request. Плагин использует TypeScript и API редактора Obsidian, не требует сторонних библиотек во время работы и не отправляет сетевые запросы.
