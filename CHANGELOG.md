# Changelog / История изменений

All notable changes to Linker4Obsidian are recorded here. / Здесь фиксируются основные изменения Linker4Obsidian.

## [0.2.0] - 2026-10-23

### English

- Added selectable UI language: Automatic (follows Obsidian), English, and Russian.
- Translated settings, conversion dialogs, notifications, and command names.
- Added English and Russian README files, with universal installation instructions for Windows, macOS, and Linux.
- Retained existing link-processing behavior and settings compatibility with 0.1.0.
- Added a formal changelog and GitHub release packaging (including a ZIP and individual plugin files).

### Русский

- Добавлен выбор языка интерфейса: автоматически по языку Obsidian, английский или русский.
- Переведены настройки, диалоги преобразования, уведомления и названия команд.
- Подготовлена документация на английском и русском языках с универсальной установкой для Windows, macOS и Linux.
- Сохранены прежние правила ссылок и совместимость настроек с 0.1.0.
- Добавлены журнал изменений и упаковка релиза GitHub (ZIP и отдельные файлы плагина).

## [0.1.0] - 2026-10-23

### English

- Initial working version of Linker4Obsidian for desktop Obsidian.
- Ordinary Wiki-links for Markdown notes; automatic embeds for supported attachments.
- YouTube URL embedding, including Shorts and live video links.
- Preview-and-confirm commands for converting links in the current note or the whole vault.
- Configurable link rules and extension overrides.

### Русский

- Первая рабочая версия Linker4Obsidian для настольного Obsidian.
- Обычные Wiki-ссылки для Markdown-заметок и встраивание поддерживаемых вложений.
- Встраивание YouTube, включая Shorts и ссылки на прямые трансляции.
- Команды преобразования ссылок в заметке или хранилище с предварительным просмотром и подтверждением.
- Настраиваемые правила типов файлов и расширений.
